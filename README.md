# 🏥 Insurance Dataset — EDA & Data Preprocessing

A hands-on Python notebook focused on **Exploratory Data Analysis (EDA) and Data Preprocessing** using an insurance dataset.

This project was created to practice the process of taking raw data, understanding its structure and quality, exploring patterns, and preparing features for Machine Learning.

---

## 🎯 Objective

The main objectives of this project were to practice:

- Understanding a new dataset
- Inspecting dataset structure and data types
- Checking missing values and duplicates
- Performing exploratory data analysis
- Understanding numerical and categorical variables
- Identifying distributions and potential outliers
- Encoding categorical features
- Scaling numerical features
- Separating features and target variables
- Splitting data into training and testing sets
- Understanding data transformations required before Machine Learning

---

## 📊 Dataset

The dataset contains information related to insurance customers, including variables such as:

- Age
- Sex
- BMI
- Number of Children
- Smoker Status
- Region
- Insurance Charges

The target variable for the Machine Learning preparation is:

**Charges**

## ⚙️ Data Preprocessing

The notebook covers several preprocessing techniques:

### Categorical Encoding

Categorical variables such as `sex`, `smoker`, and `region` are converted into numerical representations using one-hot encoding.

### Feature Scaling

Numerical input features are prepared for scaling using `StandardScaler`.

### Feature & Target Separation

The dataset is separated into:

- **X:** Input features
- **y:** Target variable (`charges`)

### Train-Test Split

The data is divided into training and testing sets to prepare it for Machine Learning.
